# Chromium 浏览器（Bot 驱动，免外部应用）

- 日期：2026-10-19
- 代码：`ds-bot/src/host/chromium.js`、`ds-bot/src/host/browse.js`、`ds-bot/test/chromium.test.js`
- 相关：[GemLogin 浏览器（Bot 驱动）](2026-10-18-gemlogin.md)、[Bot 浏览器、联网搜索、密钥和连接器](2026-10-08-browser-and-secrets.md)

## 为什么

GemLogin 通道只在装了 GemLogin 的机器上有用（设计见上一条）。很多机器没有 GemLogin，但都有 Chrome/Edge，或者至少能联网下载——给 Bot 一台它自己驱动、自己拥有的普通 Chromium，就能覆盖「面板浏览器用户操作、Bot 只读」之外的真实网页操作，不需要任何第三方应用。

## 已定的行为

- 三个工具：`chromium_open`（按名字启动/接管一个 session）、`chromium_close`（关闭）、`chromium_browse`（驱动：与 `gemlogin_browse` 完全相同的 action 集合——navigate/read/click/type/press/scroll/tabs/use_tab/back/forward/reload/wait_for/wait/screenshot/evaluate/steps/show/hide）。驱动层抽到 `src/host/browse.js`，gemlogin.js 与 chromium.js 共用。
- 浏览器二进制按顺序解析：`config.chromium` 指的路径 → 系统已装的 Chrome/Edge/Chromium/Brave（Windows 常见安装目录、macOS /Applications、其余平台扫 PATH）→ `<home>/chromium/browser/` 里已下载的 Chrome for Testing → 用 `@puppeteer/browsers` 按 `stable` tag 现下一个。解析成功即缓存，下载失败不留状态、下次 open 重试。
- 每个 session 按 `owner/name` 键控；profile 目录持久化在 `<home>/chromium/profiles/<bot>/<name>`，同名重开保留 cookie 和登录态。截图存 `<home>/chromium/shots/`。
- 默认隐藏开窗：headed 启动带 `--window-position=-32000,-32000`，随后立刻经 CDP minimize——与 GemLogin 同一招；`hidden:false` 开窗可见，`headless:true` 完全无窗（此时 `show`/`hide` 报「没有窗口可动」）。进程死了下一次操作自动按原参数重启，profile 目录不变。
- 归属：谁开谁驱动；其他 Bot 连名字都指不到（pick 只在自己 session 里找），Main Bot 可用 `owner/name` 接管或关闭。
- 客户端：Bot 详情页 Browser 标签把 Chromium session 和 GemLogin session 并列成同一种卡片——两秒轮询 JPEG、点击预览即点页面、headed 的窗口可 Show/Hide（`chromium-list`/`chromium-shot`/`chromium-show`/`chromium-click` 端点）。
- `config.chromium`：`false` 关掉这组工具；字符串或 `{ executablePath }` 强制指定二进制；`{ args }` 加启动参数。默认开。

## 不做什么

- 不做指纹、代理 profile——那是 GemLogin 的地盘；这里的 session 是普通 Chromium profile。
- 不自动更新已下载的浏览器：cache 里有的继续用。
- 不嵌浏览器画面进 webview——仍是帧流 + 点击桥，原因同 GemLogin 卡片。

## 已知限制

- 无窗口管理器的环境（无 X 的 Linux 服务器）要用 `headless:true`；headed 启动会失败。
- `evaluate` 与 GemLogin 同样是逃生门；下载链路走 Chrome for Testing 的公开 CDN，机器要能访问它。
- 系统浏览器是用户日常那个 Chrome 时，启动出来的实例用 Bot 自己的 profile 目录，不碰用户日常 profile；但也拿不到用户已登录的站点——要登录态走 GemLogin 或面板浏览器。
